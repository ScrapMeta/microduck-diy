# OpenMicroDuck（JoyandAI）

第三方**完全开源** Microduck 风格复刻平台（规划：25 cm / ≤1 kg / 15 DoF）。与 [[microduck-diy]]、[[microduck-replica]] 并列的**外部参考**，非本 diy 仓。

| 项 | 值 |
|----|-----|
| GitHub | https://github.com/JoyandAI/OpenMicroDuck |
| 本地 | `D:\projects\microduck\OpenMicroDuck` |
| 许可证 | 硬件 CERN-OHL-S · 软件 Apache-2.0 · 文档 CC BY-SA |
| 舵机路线 | **飞特平替**（样机 [[feetech-hl-2909]]；候选含 [[feetech-hd-1910]]） |
| 电池 | 18650 可拆（非 NP-F550） |
| 主控 | RK3566 同级 |

进度（README 2026-09）：HL-2909 + 打印件样机；Zero 转接 HAT 已下单。文档见仓内 `docs/servo.md`、`docs/architecture.md`。
