# image/ README — seed 镜像（摘录）

官方不发布整机刷机包。路径：Armbian Minimal for Radxa Zero 3 → provision。

本目录产出 `microduck-zero3-*-seed.img.xz`，可刷 **eMMC 或 SD**。  
底座默认 Armbian radxa-zero3 trixie vendor minimal（清华源）。  
量产文档与 updater 设计写明存储为 **eMMC**；开发可用 SD 卡刷后插板。
