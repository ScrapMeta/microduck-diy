# 机身取电经 DXL 回灌 HAT（~6 V）评估

> Issue [#9](https://github.com/ScrapMeta/microduck-diy/issues/9)。  
> **pm 裁决（2026-09-15）：不采用为装机定稿**；仅允许严格限流的台架实验。  
> 现行互联仍以 [[board-interconnect]] 为准：`NP-F550（机身）──电源线──► HAT（头舱）`。

## 1. 提案 vs 现行

| | **现行定稿** | **提案（备选）** |
|--|--------------|------------------|
| 进电 | 电池粗线 → HAT `+BATT` | 机身取电 → **~6 V** → 经 **DXL 3P 针2** 回灌 HAT |
| 舵机母线 | HAT 再经 J13/J14 把 **VBATT** 分出去 | 同一 `+BATT` 网，电流方向反过来经颈线进头 |
| 机身 IMU | 链尾/叶子，**勿穿堂大电流** | 若当注入点 = 与「勿穿堂」冲突 |

电气上：J13/J14 针2 **就是** `+BATT`，从针2灌电 **能** 点亮 HAT buck——问题不在「通不通」，在于 **载流、回流、保护、双供电**。

## 2. 拓扑是否可行

### 2.1 与官方路径的差异

官方/现行：**电池先进 HAT，再出 DXL**。舵机堵转与 Zero 启动峰值由头舱母线就近供给，颈线主要是「出」电流。

提案：**机身 6 V 经 DXL 线进头**。则：

- Zero（~1–2 A @5 V）+ 舵机母线峰值（行走常要 **数安～十几安** 级预算）都挤在 **EH 3P / Robot Cable 细线** 上过颈；
- 地回路同样经针1，与信号地、舵机回流叠在一起；
- 若电池与 Type-C **同时**给 Zero，仍属「双灌」——沿用 [[bench-power-supply]]：**勿双灌**。

### 2.2 机身 IMU 作电源注入点？

| 板 | 结论 |
|----|------|
| **2 号（单 3P）** | **不适合**。只有一口，无法「进电 + 续链」；作叶子时也不是电源汇流排 |
| **1 号（双 EH）** | 电气可并联针2，但 wiki 已写：**勿让 15 舵机电流穿堂过 IMU 铜箔**；板上仅 LDO（AP2210 一类）+ DATA 侧 TVS/串阻，**无**按主电源汇流设计的 PPTC/粗铜 |

→ **IMU 板不作整机电源注入点。** 若台架硬要「髋旁进 6 V」，用 **独立 Y 线/接线柱并联到 VBATT**，电流 **不经过** IMU 芯片区铜箔。

### 2.3 风险摘要

| 风险 | 说明 |
|------|------|
| 颈线过载 | 细 3P 线压降大、发热、偶发掉压 → Zero 复位 / 舵机欠压 |
| 回流 | 堵转电流经针1 回流，地弹影响 TTL |
| 反接/浪涌 | 机身端若无防反，灌进 HAT/`+BATT` 与舵机；IMU LDO Vin 虽宽仍怕反接 |
| 双供电 | HAT 母线 + Zero Type-C 并行 → 倒灌风险 |

## 3. 「约 6 V」是否合适

### 3.1 XL330 / 母线

| 来源 | 电压 |
|------|------|
| Robotis XL330 手册 | **3.7–6.0 V**（推荐约 5 V） |
| 整机现行 / NP-F | **~6.6–8.4 V**（已知超手册上限，官方路径如此） |
| 提案 6 V | **落在手册上限**，对舵机比 8.4 V **更友好**；扭矩/转速相对 7.4 V 会略降 |
| **DIY 实测（2026-09-15）** | 台供 **~7.2 V**：舵机红灯**持续闪**（过压报警）；**~6.5 V**：上电闪一下后正常 |

XL330 手册工作区 **3.7–6.0 V**；控制表默认 **Max Voltage Limit ≈ 7.0 V**。超过后 Hardware Error Status bit0（Input Voltage Error），LED 报警闪、需重启清。  
→ **你这批舵机不宜用 NP-F 满电直供（~8.4 / 标称 7.4）当母线**；台架/装机母线建议稳在 **约 6.0–6.5 V**（粗线进 HAT，仍不经 IMU）。

台架单舵：6.0–6.5 V 合理。整机行走：扭矩相对 2S 直供会略降，需实测是否够。

### 3.2 HAT AP63205（→ 5 V）

| 项 | 判断 |
|----|------|
| 输入范围 | HAT 标称 **5–28 V** → **6 V 在舒适区** |
| 压差 | 6→5 V 同步 buck 可工作；轻载注意最小导通/纹波 |
| 负载 | Zero + 音频等走 5 V；**舵机不走 buck**（仍在 `+BATT`） |

### 3.3 要不要「再稳压」

| 场景 | 建议 |
|------|------|
| 台供已稳在 **6.0–6.5 V** | **不必**再叠一级；直接粗线进 HAT `+BATT` |
| NP-F 2S（7–8.4 V） | **DIY 建议机身加 buck → ~6.0–6.5 V** 再粗线进 HAT（见上实测）；官方整机仍有 2S 直供先例，与手册/你板实测冲突时以实测为准 |
| 仅保护 Zero 5 V | HAT 已有 AP63205，**不必**为 Zero 再加 LDO |
| 理想二极管 | 仅当「电池 + 台供 / 双路」并存时考虑；现行策略是 **禁止双灌**，优先开关切换而非 OR |

## 4. 接口与保护（若只做台架实验）

```
台供/电池 ──► [可选 buck → 6 V] ──粗线(+ / GND)──► HAT +BATT / GND
                                      │
                                      └── 勿经 IMU 铜箔
DXL 3P 仍只作：HAT ──► 舵机 / IMU（通信 + 从 HAT 出的 VBATT）
```

- 机身「电源口」：XT30 / 台供夹线 / 电池扣 → **粗线到头舱**；与 IMU 3P **电气可并联 VBATT，机械分开**。  
- 反接：机身进电加防反（肖特基/理想二极管）优先于指望 IMU。  
- Type-C：HAT 已供电时 **拔掉** Zero 墙充。

## 5. 裁决与推荐

| 选项 | 结论 |
|------|------|
| **装机定稿** | **不采用**「经 DXL 3P 回灌 HAT」替代粗线进 HAT |
| **台架实验** | **可以**：6 V / 限流；**粗线**进 `+BATT`；单只或少舵机；示波器/通信仍归 #4/#7 |
| **6 V 本身** | DIY **推荐**母线 **~6.0–6.5 V**（实测 7.2 V 持续闪灯）；用 **粗线进 HAT**，不绑 DXL 回灌 |

### 不可破约束

1. 互联真源仍是 [[board-interconnect]]：电池 → **电源线** → HAT。  
2. 机身 IMU **禁止**作整机主电源穿堂点。  
3. 未评估改线前，禁止「电池只挂 IMU 链、长期堵转」。  
4. 勿 Type-C 与 `+BATT` 双灌。  
5. #4 / #7 / #8 通信排障 **不阻塞**；本评估不改其步骤。

### 若将来「要 6 V 母线」的正确草图

```
NP-F / 台供
    │
    ▼
  buck → 6 V（电流按行走预算，台架可 5–10 A 级电源）
    │
    ├── 粗线 + / GND ──► HAT +BATT（头舱）──► AP63205 → 5 V → Zero
    │                         │
    │                         └── J13/J14 VBATT ──► 舵机 / IMU
    └──（可选）本地测点；不经过 imu_to_dxl 芯片区
```

### 粗线规格（电池/台供 → HAT，过颈）

| 用途 | 建议 |
|------|------|
| 材料 | **硅胶多股铜线**（软、耐折、过颈）红黑一对 |
| **台架 / 少舵机** | **18 AWG（≈0.75–0.8 mm²）** 起 |
| **整机行走预算（对齐 5–10 A 台供）** | **16 AWG（≈1.25–1.5 mm²）**；余量大用 **14 AWG（≈2.0 mm²）** |
| 勿用 | Robot Cable / EH 芯线当主电源；勿经 IMU 板铜箔 |
| 头舱落地 | **J3 或 J11** 针1/2，或 C19 飞线；J13/J14 留给两路舵机束 |

短线（机身→头，往返约几十厘米）压降通常可接受；优先保证 **峰值电流余量** 与弯折寿命，而非再加粗到 10 AWG（头舱难走线）。

### 电流预算（粗）

| 负载 | 粗量 |
|------|------|
| Zero + 外设 @5 V | ~1–2 A → 6 V 输入约 **1.2–2.5 A** |
| 单 XL330 空载 | ~0.1–0.3 A |
| 单只堵转 | ~1.5 A 量级 @~5–6 V |
| 15 只行走峰值 | 需 **数安以上**；细 DXL 线 **不够** |
