## 3. 建议焊接顺序（手工 · 2026-09-12）

> POS 真源：`ASE01187-C1_elec_RPI_Robot_HAT_POS.csv`。  
> **约定：** 丝印朝上 = **top**；叠 Zero 的那面（含 **J4**）= **bottom**。

### 3.1 正反分布（关键）

| 面 | 难焊 / 高件 | 其余 |
|----|-------------|------|
| **bottom** | **U2** VQFN · **U8** · U1 · U5–U7 · **U10** · **Y1** · **J4**（2×20）· Q2 · D1/D2/D4 | 大量 0402、FB、TH1 |
| **top** | **U11** BMI088 LGA · **U9** · U3 · **L4** · C19 · 全部 EH/SH/Wago · MK1 | 部分阻容 · Q1 |

→ 难 IC **多数在底面**；正面难的是 BMI088 + buck + 座子。

### 3.2 推荐工艺（现行 · 2026-09-12）

**底面：加热焊台一次回流** → **正面：夹具 + 风枪** → **最后 J4**。

| 步 | 面 | 做法 |
|----|-----|------|
| 1 | **bottom** | 锡膏（钢网或针筒）→ 贴全底面 SMD（含 U2/U8/U1/U10/Y1 等）· **J4 焊盘留空不贴** · DNP 不贴 |
| 2 | **bottom** | **加热焊台一次性回流**（整面一起熔）；冷至可碰再取板 |
| 3 | 目检底 | 重点 U2 桥连 / Y1 方向 / 缺脚；必要时风枪局部补 |
| 3b | **底面短路测** | 见 §3.5；**通过后再贴正面**（省 BMI088） |
| 4 | 翻面 | 夹具夹边；底面已回流件 **架空**，勿压焊台/桌面 |
| 5 | **top** | **低温锡膏** + **风枪**（可分区）：U11 → U9 → U3 → 阻容 → L4/C19 |
| 6 | **top** | 座子 EH/SH/Wago/MK1（J3/J11 可省）；塑料件控温 |
| 7 | 再翻 | **最后焊 J4**（烙铁或局部风枪） |

### 3.3 加热焊台 / 夹具 / 二次受热

- 底面一次回流很适合本板：**难 IC 多在 bottom**。  
- 曲线大致：预热 → 爬升过液相 → 短保温 → 自然/风冷；跟锡膏牌号，勿长时间空烤。  
- **J4 勿进第一次回流**：高座翻面难放平，且二次受热伤座。  
- 顶面风枪时底面朝下：高温海绵/支架架空 U2 等。  
- 夹 **板边** / Fiducial 附近，勿夹 LGA/VQFN。  
- U4 / §1 DNP 仍不贴；BMI088 只 1 颗，贴片对位要准。

#### 底面会不会掉？（会，要防）

板厚 **1.0 mm / 4 层**，正面风枪热量容易传到背面。背面已焊件朝下时，若锡再次到液相，**小件（0402）最容易掉/移位**，U2 等大 IC 也可能松。

| 策略 | 做法 | 推荐 |
|------|------|------|
| **A. 双温锡膏（首选）** | 底面 **SAC305**（~217 °C）一次回流；正面 **低温锡** Sn42Bi58 等（~138 °C） | ✅ |
| B. 同膏 + 点胶 | 底面回流前对较重 IC 点红胶/SMT 胶，再回流 | 无低温锡时 |
| C. 同膏硬吹 | 正面极局部、短时风枪，整板勿烘透 | 风险最高，仅补焊 |

→ **正面建议用低温焊锡/低温膏**，不是必须“整个工艺都低温”，而是**第二次受热那一面**用低熔点，保护已焊底面。

#### 风枪温度（参考，按膏与嘴调）

| 用途 | 喷嘴气温（常见起点） | 备注 |
|------|----------------------|------|
| 正面 **低温锡**（SnBi ~138 °C） | **240–280 °C** 更稳；**200 °C 偏紧** | 显示是气流温，焊点常低几十度；小嘴、小风量；板可预热 80–100 °C |
| 正面若误用 **SAC305** | 300–350 °C | 更易烫穿到底面，不推荐作二次面 |
| BMI088 / 小 IC | 偏下限 + **小嘴** 定点 | 忌大嘴扫整板 |
| EH / Wago / 麦 | 更短、更凉；可改烙铁 | 防壳熔 |

**本板实操（2026-09-13）：** 底面已用 **~183 °C 锡膏**（SnPb 共晶一类）+ 加热台 **215 °C** 回流完成——对 183 °C 膏，峰值 215 °C 合理（略保守）；焊点光亮、无虚焊即可。正面拟 **138 °C 膏**：目标焊点约 **150–170 °C**，须 **低于 ~180 °C**，以免底面再熔脱落。风枪 **200 °C** 对底面安全，但对熔 138 °C 膏往往不够，建议 **240–260 °C 起调**，短吹、看锡熔再停；勿长时间烘整板。

辅助：正面可先用预热台/热风从下方 **仅预热到 ~80–100 °C**（勿让底面到液相），再上面小嘴焊接，缩短风枪时间。

目检底面：每吹完一个正面大件，翻看 0402/IC 是否移位。

### 3.4 目检

桥连（尤其 U2、U11、U8）→ 酒精清洁 → 再进上电前检查。

### 3.5 底面回流后 · 短路测（焊正面之前）

**要做。** 此时 **不要上电**（`U9`/`L4`/`U3`/`C19` 在正面，5 V / 1V8 路径未齐）。

万用表 **蜂鸣/二极管档**，表笔接焊盘或未装的 **J4 焊盘**（J4 在 bottom，有 `+5V` / `+3V3` / `GND`）。

| # | 测 | 期望 | 说明 |
|---|-----|------|------|
| 1 | 目视 U2（VQFN）· U8 · U1 · Y1 | 无桥锡、无缺脚、晶体方向对 | 优先于电测 |
| 2 | **`+BATT` ↔ `GND`** | **不响**（或阻值很高，非≈0 Ω） | 可从 C19 焊盘（正面未贴也可探铜）、或原理图电池/电机相关底面焊盘 |
| 3 | **`+5V` ↔ `GND`** | **不响** | J4 的 5V 脚焊盘；底面已有 U10 等挂在 `+5V` |
| 4 | **`+3V3` ↔ `GND`** | **不响** | J4 的 3V3 脚；底面 U2 已挂 `+3V3` |
| 5 | **`+1V8` ↔ `GND`** | **不响** | U2 相关去耦焊盘；正面 U3 未贴时轨仍可能经 U2 可测 |
| 6 | U2 / U8 相邻细脚 | 邻脚之间 **不响** | 怀疑桥锡时重点扫 |

注意：

- **0 Ω 跳线、电感、磁珠**两端会响，属正常，别当成电源对地短路。  
- 电容未充时可能瞬间低阻，以稳定后读数为准。  
- **TP2–TP4 在正面**且是音频节点，本步不用。  
- 全绿 → 再贴正面；有对地短路 → **先修底面**，勿焊 BMI088。

## 4. 正面贴完 · 分步测试（现行）

> 按你当前配置：**无 U11** · **J13/J14 TTL** · **MK1 + J1 喇叭** · 不要 485/外置麦。  
> **全程限流台供优先**；电池放到电压轨验证之后。

### 4.0 工具

万用表 · 限流台供（可调 7–8.4 V，电流限 **0.3 A 起**）· Zero 3W（已刷系统更好）· 可选：1 只 XL330、4 Ω 喇叭、耳机/录音软件

### 4.1 目视（不上电）

- [ ] 正面：U9 / L4 / C19 / U3 / J4 / J13 / J14 / J1 / MK1 方向、桥锡、虚焊  
- [ ] 翻面：0402 有无因二次受热移位/脱落  
- [ ] U11 空位正常；J3/J11 未贴正常  

### 4.2 断电短路复测

蜂鸣档，**不插 Zero、不通电**：

| # | 测 | 期望 |
|---|-----|------|
| 1 | `+BATT` ↔ `GND`（C19 / 电池口相关焊盘） | 不导通（非 ≈0 Ω） |
| 2 | `+5V` ↔ `GND`（J4 脚或 U9 输出侧） | 不导通 |
| 3 | `+3V3` ↔ `GND`（J4） | 不导通 |
| 4 | `+1V8` ↔ `GND`（U3 输出） | 不导通 |
| 5 | J13 / J14：针 2（VBATT）↔ 针 1（GND） | 不导通 |

异常 → **先修，勿上电。**

### 4.3 只 HAT 上电（不叠 Zero）

1. 台供：**+** → HAT `+BATT` 入口（电机/电池口或 J13/J14 的 **针 2**，与原理图一致即可）· **−** → `GND`  
2. 电压先 **7.4 V**（或 8.0 V），限流 **0.3–0.5 A**  
3. 合闸：限流灯不应死亮；电流大致数十 mA 级（无 Zero）  
4. 测压：

| 点 | 期望 |
|----|------|
| `+BATT` | ≈ 台供电压 |
| **`+5V`**（J4 的 5V 脚 / AP63205 输出） | **≈ 5.0 V**（±0.2） |
| **`+1V8`**（U3 输出） | **≈ 1.8 V**（若 U3 已贴） |
| `+3V3` | **此时可能仍接近 0**（多由 Zero 经 J4 供给）→ 正常，进下一步再看 |

5V 不对 / 电流顶死 → 断电查 U9/L4/极性/桥锡。

### 4.4 叠 Zero · 系统起来

1. **断电**后叠好 **J4**（防反插）  
2. 再同上台供限流上电（可把限流提到 **1–1.5 A**，Zero 启动峰值要余量）  
3. Zero 应亮灯、能启动；测：

| 点 | 期望 |
|----|------|
| J4 `+5V` | ≈ 5 V |
| J4 `+3V3` | ≈ 3.3 V |

4. SSH / 串口进系统（按你现有 [[zero3w-bench-plan]] / [[system-flash-armbian]]）

### 4.5 I²C · 音频 codec

板载 AIC3104 地址 **`0x18`**，多在 **i2c3**：

```bash
sudo i2cdetect -y -r 3
# 期望在 0x18 看到器件（具体总线号以设备树为准；也可用 i2cdetect -l 先列总线）
```

- 有 `18` → codec 供电与 I²C 基本通  
- 没有 → 查 U2/U3/Y1、i2c3 overlay、`aic3104` 相关 dtbo（官方 `setup-board.sh` 路径）

### 4.6 喇叭（J1）

1. 断电，**4 Ω 3–5 W** 喇叭接到 **J1**（注意 PAM8406 差分输出，按丝印/原理图两线，勿对 GND 短接单端乱接）  
2. 上电后走官方音频初始化（`aic3104-init` / `amixer` 一类）  
3. 播测试音，例如：

```bash
speaker-test -c 2 -t wav
# 或 aplay 任意短 wav；设备名常见 plughw:aic3104（以 aplay -l 为准）
```

有声 → 功放 + codec 输出 OK。无声：先 `aplay -l`、混音器音量/mute，再查 U1/J1。

### 4.7 板载麦（MK1）

```bash
arecord -d 3 -f cd /tmp/mic-test.wav && aplay /tmp/mic-test.wav
```

能录到环境声 → Mic3R 路径 OK。爆音/全静：查 MK1 方向、codec 路由。

### 4.8 Dynamixel TTL（J13 / J14）

针脚：**1=GND · 2=VBATT · 3=DATA**（两座电气并联）。测不通完整流程：[[hat-dxl-bus-debug]]。

1. **先不接舵机**：确认针 2 上电后为电池母线电压（≈台供）  
2. 确认 `/dev/ttyS2` 存在，且 **无 getty 占用**（官方会 mask `serial-getty@ttyS2`）  
3. 接 **1 只** XL330（ID 已知），短线 EH 3P  
4. 用 U2D2 对照 / SDK / `robotd` 扫 ID；示波器看 DATA 问包+回包  

再扩到多舵机；机身 IMU ID 200 另测。

## 6. 正面可省焊（按你的目标）

> 目标假定：**要供电 + TTL 3P 舵机 + 板载麦 + 喇叭**；**不要头 IMU**；**不要 485**；ToF 可后装。

### 6.1 可以先不焊

| 位号 | 原因 |
|------|------|
| **U11 BMI088** | 官方软件 `dormant`；你说先不要头 IMU → **整颗可不贴** |
| **U11 专用周边（建议一并省略）** | **C23, C24**（`U11-VDD` 去耦）· **R9**（3V3→U11-VDD）· **R14**（SDO1 上拉）· **R15**（SDO2 下拉）· **R25**（INT1 串阻） |
| **J3 / J11 · U8** | RS-485 整路（见下） |
| **J2 / J9** | 外置麦 Wago；用板载 **MK1** 即可 |
| **J5–J8** | Qwiic/ToF · 台架后期再贴也行 |
| **H2 / TP2–TP4** | 测试点，可选 |
| **U4** | 本就 DNP |

**U11 周边若已经贴上：一般无功能问题**（多几颗对地电容/空脚上下拉），不必拆；只是费料。勿把旁边 **Q1 / R26 / R27**（DXL/音频）或 **J7** 当成 IMU 件删掉。

### 6.2 这轮建议要焊（正面）

| 位号 | 原因 |
|------|------|
| **U9 · L4 · C19** + buck 周边阻容 | 电池 → **5 V** 给 Zero / 功放 |
| **U3** + 周边 | **1V8**（codec U2 已在背面，要出声/录音需它） |
| **J13 / J14** | TTL **3P** DXL |
| **J4** | 叠 Zero（仍建议最后焊） |
| **MK1** | 板载 MEMS 麦 |

### 6.3 麦与喇叭

| 项 | 规格 |
|----|------|
| **官方麦** | 板载 MEMS **MK1**；BOM 仅写 `Microphone_MEMS`；立创/淘宝对料 **`LMA2718T421-OA5-2`（C7587901）**。软件走 codec **Mic3R**。外置麦（J2/J9）非必须。 |
| **喇叭** | 接 **J1**（Wago）。文档口径「**5W**」；功放 **PAM8406 @5V** 对 **4 Ω ≈ 3 W**（2 Ω 才到标称 5 W）。采购：**4 Ω、额定 3–5 W** 小喇叭（直径按头壳/网格 `speaker` 孔选，常见 28–40 mm）。勿低于 2 Ω。 |

### 6.4 RS-485 焊接（DIY 定稿 2026-09-14）

> Microduck 装机走 **TTL（J13/J14）**，**不用 485**。软件/舵机都是 XL330 单线半双工。

#### 可省（485 专用）

| 位号 | 型号 / 值 | 层 | 说明 |
|------|-----------|-----|------|
| **U8** | SIT3088E | bottom | 485 PHY，只驱动 4P |
| **J3、J11** | B4B-EH-A 4P | top | 485 舵机座 |
| **R40** | 0R | bottom | `Dynamixel_dir` → U8 `~RE`；无 U8 无用 |

#### 必须留（即使不用 485）

| 位号 | 值 | 说明 |
|------|-----|------|
| **R29** | 10k | `U8-RO` 上拉到 3V3，进 **U5**。U8 不贴时尤其要贴，否则 U5 输入浮空，TTL 可能不稳 |
| **C15** | 100n | 3V3–GND 去耦（U8 旁，但是电源去耦，不是 485 功能件） |
| **U5 / U6 / U7** | 74LVC1G08 / 1G125 / 1G126 | TTL 半双工方向/缓冲 |
| **R31 / R32** | 10k | TTL 逻辑周边 |
| **J13 / J14** | EH 3P | 装机舵机口 |
| **TH1** | 100R 热敏 | TTL 口保护 |
