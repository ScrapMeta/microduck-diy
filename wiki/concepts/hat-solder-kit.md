## 3. 焊接工艺（手工 · 2026-09-12 / 13 实操）

> 丝印朝上 = **top**；叠 Zero 那面（含 **J4**）= **bottom**。板 **1.0 mm / 4 层**。

### 3.1 正反分布

难 IC **多在 bottom**：U2 VQFN · U8 · U1 · U5–U7 · U10 · Y1 · **J4** · Q2 · D1/D2/D4 ＋ 大量 0402。
**top** 难的是 **U11** BMI088 LGA · U9 · U3 · L4 · C19 ＋ 全部座子 · MK1。

### 3.2 推荐工艺（现行）

**底面加热台一次回流 → 正面夹具 ＋ 风枪 → 最后 J4。**

1. bottom：锡膏 → 贴全底面 SMD（**J4 焊盘留空** · DNP 不贴）
2. bottom：**加热台整面一次回流** → 冷至可碰再取板
3. 目检底（**U2 / U8 桥连重灾区** · Y1 方向 · 缺脚 · 桥连先酒精清洁）→ **底面短路测 §3.4**（过了再贴正面，省 BMI088）
4. 翻面：夹**板边 / Fiducial 附近**（勿夹 LGA / VQFN），底面已焊件**架空**
5. top：**低温锡膏 ＋ 风枪**：U11 → U9 → U3 → 阻容 → L4 / C19
6. top：座子 EH / SH / Wago / MK1（J3/J11 可省）—— 塑料件控温
7. 再翻：**最后焊 J4**（烙铁或局部风枪）

**温度（实测基调）**：底面 **183 °C 膏（SnPb 共晶）＋ 加热台 215 °C** 一次回流已成功（2026-09-13，峰值略保守，看焊点光亮无虚焊）。
正面 **Sn42Bi58 ≈138 °C 低温锡** → 目标焊点 **150–170 °C · 须 < ≈180 °C**；风枪 **240–260 °C** 起调（显示是气流温，焊点常低几十度；200 °C 对熔 138 °C 膏往往不够），小嘴短吹、看锡熔即停；可先下方预热 **80–100 °C**（勿让底面到液相）。**J4 勿进第一次回流**（高座翻面难放平 ＋ 二次受热伤座）。

### 3.3 底面会不会掉？（会，要防）

正面风枪热量会传到背面：小件（0402）最易掉 / 移位，U2 等大 IC 也可能松。
**首选双温锡膏** —— 底面 **SAC305（≈217 °C）** ＋ 正面**低温锡（≈138 °C）**；无低温锡则对重件点红胶；同膏硬吹风险最高（仅补焊用）。BMI088 **只 1 颗**，贴片对位要准。

### 3.4 底面回流后 · 短路测（焊正面之前 · 不上电）

此时 `U9` / `L4` / `U3` / `C19` 未贴，5V / 1V8 路径未齐 —— **不要上电**。
蜂鸣 / 二极管档，探未装的 **J4 焊盘**或对应铜箔：`+BATT` · `+5V` · `+3V3` · `+1V8` ↔ `GND` **均不响**；U2 / U8 邻脚不响；目视 U2 / U8 / U1 / Y1 无桥锡缺脚。
注意：**0 Ω 跳线 / 电感 / 磁珠两端会响属正常**；电容未充时可能瞬时低阻，以稳定后读数为准。全绿再贴正面；有对地短路先修底面，**勿焊 BMI088**。

## 4. 正面贴完 · 分步测试（现行）

> 本机配置：**不要头 IMU（U11 空）** · **TTL J13/J14** · **MK1 ＋ J1 喇叭** · 不用 485 / 外置麦。**全程限流台供优先**，电池放到电压轨验证之后。

### 4.0 工具

万用表 · 限流台供（可调 7–8.4 V，**限流 0.3 A 起**）· Zero 3W（已刷系统更好）· 可选 1 只 XL330 ＋ 4 Ω 喇叭。

> **接舵机降到 6.0–6.5 V** —— §4.3 的 7.4 V 只适用于**裸 HAT**（AP63205 输入 5–28 V 无妨）；这批 XL330 实测 **≈7.2 V 即过压报警且锁存 torque off** → [[bench-power-supply]] · [[dynamixel-xl330]]。

### 4.1 目视（不上电）

正面 U9 / L4 / C19 / U3 / J4 / J13 / J14 / J1 / MK1 方向 · 桥锡 · 虚焊；翻面查 0402 有无因二次受热移位 / 脱落。**U11 空位、J3 / J11 未贴属正常**。

### 4.2 断电短路复测（不插 Zero · 不通电）

`+BATT` · `+5V` · `+3V3` · `+1V8` ↔ `GND` 均不导通；**J13 / J14：针 2（VBATT）↔ 针 1（GND）不导通**。异常 → **先修，勿上电**。

### 4.3 只 HAT 上电（不叠 Zero）

台供 **+** → `+BATT` 入口（J13/J14 针 2 或电池口，与原理图一致）· **−** → `GND`；电压先 **7.4 V**（或 8.0 V），限流 **0.3–0.5 A**——**仅裸 HAT**：不接舵机、不垫舵机排线。
合闸：限流灯不应死亮，电流大致数十 mA 级（无 Zero）。测 —— `+BATT` ≈ 台供电压 · **`+5V`（J4 的 5V 脚 / AP63205 输出）≈ 5.0 V（±0.2）** · `+1V8`（U3 输出）≈ 1.8 V（U3 已贴时）· `+3V3` **此时可能仍 ≈ 0**（多由 Zero 经 J4 供给 → 正常，进下一步再看）。

5V 不对 / 电流顶死 → 断电查 U9 / L4 / 极性 / 桥锡。

### 4.4 叠 Zero · 系统起来

断电后叠 **J4**（防反插）→ 台供限流提到 **1–1.5 A**（Zero 启动峰值要余量）上电 → Zero 亮灯可启动 → **J4 `+5V` ≈ 5 V · `+3V3` ≈ 3.3 V** → SSH / 串口进系统（[[zero3w-bench-plan]] · [[system-flash-armbian]]）。

### 4.5 I²C · 音频 codec

```bash
sudo i2cdetect -y -r 3   # 期望 0x18（AIC3104）· 总线号以设备树为准，可先 i2cdetect -l
```

有 `18` → codec 供电与 I²C 基本通；没有 → 查 U2 / U3 / Y1 · i2c3 overlay · 官方 `setup-board.sh` 相关 dtbo。

### 4.6 喇叭（J1）

断电接 **4 Ω 3–5 W** 喇叭到 **J1**（PAM8406 **差分输出**：按丝印 / 原理图两线，勿对 GND 单端乱接）→ 上电走官方音频初始化（`aic3104-init` / `amixer` 一类）→ `speaker-test -c 2 -t wav`（或 `aplay` 任意短 wav；设备名常见 `plughw:aic3104`，以 `aplay -l` 为准）。
有声 → 功放 ＋ codec 输出 OK；无声 → 先 `aplay -l`、混音器音量 / mute，再查 U1 / J1。

**座型 · 怎么插拔**（J1 = WAGO **2059-302/998-403** · LCSC `C2765060` · **PUSH WIRE® 弹簧夹** · 2P · 3 mm · 高 2.7 mm —— 不是螺丝端子 / 扳手式）：

- **插** —— **硬（单股）线**剥好后直插到底：0.14–0.34 mm²（26–22 AWG）剥 **4–5.5 mm** · 0.5 mm²（20 AWG）剥 **6–7.5 mm**；多股软线直捅 = 插不进 / 接触不良 → 先**镀锡**（或压管状端子）做成硬头
- **拔** —— 小一字批（或 WAGO **2059-189** / **206-859**）插进座上**圆操作孔**轻压 → 弹簧张开 → 抽线；备选「twist & pull」（≤ 10 次）。0.5 mm² 用过之后**不能再接更细的线**
- **两脚是什么**（PCB 网表）—— **pin1 = U1 `+OUT_R`（经 FB3 ＋ C9）** · **pin2 = U1 `−OUT_R`（经 FB2 ＋ C8）**：**两脚都不是 GND**（BTL 差分，碰地 = 输出短路）· 接反只反相不烧 · **只引出右声道**；**J2 / J9 同型号但接外置麦**，别插错

### 4.7 板载麦（MK1）

```bash
arecord -d 3 -f cd /tmp/mic-test.wav && aplay /tmp/mic-test.wav
```

能录到环境声 → Mic3R 路径 OK；爆音 / 全静 → 查 MK1 方向 · codec 路由。

### 4.8 Dynamixel TTL（J13 / J14）

针脚 **1=GND · 2=VBATT · 3=DATA**（两座电气并联）。

1. **先不接舵机**：确认针 2 上电后为电池母线电压（≈ 台供）
2. 确认 `/dev/ttyS2` 存在且**无 getty 占用**（官方 mask `serial-getty@ttyS2`）
3. 接 **1 只** XL330（ID 已知）· 短线 EH 3P
4. U2D2 对照 / SDK / `robotd` 扫 ID；示波器看 DATA 问包 ＋ 回包

测不通完整流程：[[hat-dxl-bus-debug]]；机身 IMU（ID 200）另测。

## 6. 免焊 / 必焊（目标：供电 ＋ TTL 3P ＋ 板载麦 ＋ 喇叭；不要头 IMU · 不要 485）

### 6.1 可以先不焊

| 位号 | 原因 |
|------|------|
| **U11 BMI088** ＋ 周边 **C23 / C24 · R9 · R14 / R15 · R25** | 只管头 IMU（官方软件 dormant）；你说先不要 |
| **U8 · J3 / J11 · R40** | RS-485 整路（见 §6.4） |
| **J2 / J9** | 外置麦 Wago —— 用板载 **MK1** 即可 |
| **J5–J8 · H2 / TP2–TP4** | Qwiic / ToF · 测试点，都可后贴（U4 本就 DNP，见 §1） |

U11 周边若已贴：**一般无功能问题**（多几颗对地电容 / 空脚上下拉），不必拆；只费料。勿把旁边 **Q1 / R26 / R27**（DXL·音频）或 **J7** 当 IMU 件删掉。

### 6.2 这轮建议要焊（正面）

**U9 · L4 · C19** ＋ buck 周边（电池 → 5 V）· **U3** ＋ 周边（1V8，codec 要它）· **J13 / J14**（TTL 3P）· **J4**（叠 Zero，仍建议最后焊）· **MK1** · **J1**（喇叭）· Q1 ＋ 音频正面阻容（按丝印别漏）。背面已贴的 **U1 · U2** 保留。

### 6.3 麦与喇叭

| 项 | 规格 |
|----|------|
| **官方麦** | 板载 MEMS **MK1** · BOM 仅写 `Microphone_MEMS`；对料 **`LMA2718T421-OA5-2`（LCSC C7587901）** · 软件走 codec **Mic3R**；外置麦（J2 / J9）非必须 |
| **喇叭** | 接 **J1**（Wago）· 文档口径「5 W」，但功放 **PAM8406 @5 V 对 4 Ω ≈ 3 W**（2 Ω 才到标称）→ 买 **4 Ω、额定 3–5 W**，**勿低于 2 Ω** |
| **净空**（2026-09-19 上游 CAD 实测） | `speaker` 网格是**矩形占位体**，包围盒 **35 × 25 × 7 mm**（同脚本算 HAT = **65.0 × 30.0 mm**，与实板吻合 → 尺度可信）→ **按矩形净空挑，或实测头壳出声孔**；别直按「Ø30 圆喇叭」下单 |
| **出声孔**（存疑） | 头壳网格**未检出** 35 mm 级出声孔（只检出 2–2.8 mm 螺丝孔 ＋ 2 个 **Ø13.5 × 1.2 mm** 浅孔）→ 可能栅格被逆向网格简化掉，**仍须看实物**，勿据此开孔 |

### 6.4 RS-485 焊接（DIY 定稿 2026-09-14）

Microduck 装机走 **TTL（J13/J14）**，软件 / 舵机都是 XL330 单线半双工 → **不用 485**。

- **可省（485 专用）**：**U8** SIT3088E（bottom · 只驱动 4P）· **J3 / J11** B4B-EH-A（top）· **R40** 0R（`Dynamixel_dir` → U8 `~RE`，无 U8 无用）
- **必须留（即使不用 485）**：**R29** 10k（`U8-RO` 上拉 3V3 → 进 U5；U8 不贴时尤其要贴，否则 U5 输入浮空、TTL 可能不稳）· **C15** 100n（3V3–GND 去耦）· **U5 / U6 / U7**（TTL 方向 / 缓冲）· **R31 / R32** 10k · **J13 / J14** · **TH1** 100R 热敏
- U8 若已焊上：**不必拆**；不焊 J3 / J11 就不会接到 485 设备
