# microduck-diy · 手搓小小鸭

**挑战：一个月手搓一只小小鸭（Microduck）。**

## Day 1 里有什么

- `Microduck_RL_3D_Print_Guide.pdf`：名称 / 数量 / 是否入结构 / 说明 / 四色参考
- `stl/`：结构用到的 **38** 种 STL
- `microduck_rl_assembly.3mf`：装配姿态分件组合（适合 Bambu 等）
- `microduck_rl_exploded.3mf`：爆炸姿态分件组合

网格来自公开的 Microduck RL 仿真资源；**不是官方量产装箱清单**。官方开放的是软件栈，机械与实机可能仍有差异。导入 STL 时请确认单位缩放（常见需 ×1000 到毫米）。
